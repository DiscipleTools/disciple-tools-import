# Disciple.Tools Import (Deprecated)

> **This plugin is deprecated and no longer maintained.** CSV import is built into the Disciple.Tools theme as of version 1.71.0. Deactivate and delete this plugin.

CSV import now lives in the theme under **Utilities (D.T) > CSV Import** in WP Admin. It imports records of any Disciple.Tools post type from a CSV file, with field mapping, a preview, duplicate checking and optional geocoding.

The final release of this plugin loads nothing, so it doesn't conflict with the theme's importer.
